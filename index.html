සිංහල & English

📚 විභාග විෂය නිර්දේශ අන්තර්ගතය (Quiz Syllabus Coverage)

1. Number Systems (ද්වීමය හා සංඛ්‍යා පද්ධති)

Binary to Dec, Hex, Octal, 2's Complement, Binary Addition, Storage Units (GB, MB, KB).

2. Spreadsheets (පැතුරුම්පත් සූත්‍ර)

SUM, AVERAGE, MAX, MIN, COUNT, IF conditions, Cell references ($A$1).

3. Logic Gates (තාර්කික ද්වාර)

AND, OR, NOT, NAND, NOR, XOR truth tables and Boolean expressions.

4. HTML & Web (වෙබ් නිර්මාණය)

HTML tags, attributes, tables, forms, CSS properties and hex color codes.

5. Pseudocode & Algorithms (පාලන ව්‍යුහ)

While loops, For loops, If-Else conditions, Modulo calculations, Trace tables.

6. SQL & Database (දත්ත සමුදාය)

SELECT, WHERE, ORDER BY, Primary Keys, Foreign Keys, aggregate functions.
